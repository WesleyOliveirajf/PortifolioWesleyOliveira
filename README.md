# Portfólio — Wesley Oliveira

Portfólio profissional bilíngue de Wesley Oliveira, Analista de Sistemas Pleno com foco em backend, inteligência artificial, automação, integrações e dados.

## Acessar

[https://portfolio-wesley-oliveira.vercel.app](https://portfolio-wesley-oliveira.vercel.app)

## Conteúdo

- Apresentação profissional em português e inglês
- Experiência e trajetória em tecnologia
- Projetos e estudos de caso selecionados
- Formação e certificações
- Stack técnica organizada por área
- Links para currículo, GitHub, LinkedIn e contato
- Layout responsivo com identidade visual inspirada em terminal

## Tecnologias

- JavaScript e JSX
- HTML e CSS
- Componentes React
- Site estático servido com `serve`
- Deploy na Vercel

## Estrutura principal

```text
PortifolioWesleyOliveira/
├── index.html              # redirecionamento para a versão principal
├── Portfolio Wesley - Mono.html
├── mono-portfolio.jsx      # versão principal do portfólio
├── portfolio-data.js       # conteúdo profissional estruturado
├── locale.jsx              # alternância PT/EN
├── uploads/                # currículo e arquivos públicos
├── vercel.json             # configuração de deploy
└── package.json
```

## Executar localmente

Pré-requisitos:

- Node.js
- npm

```bash
npm install
npm start
```

Acesse [http://localhost:3000](http://localhost:3000).

## Decisões do projeto

- Conteúdo separado da apresentação para facilitar manutenção
- Suporte a português e inglês
- Navegação por seções em uma única página
- Deploy estático simples e reproduzível
- Links diretos para evidências profissionais e projetos no GitHub
